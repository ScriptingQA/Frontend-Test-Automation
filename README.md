# 🧪 QA Automation Portfolio – ScriptingQA

Welcome to my Test Automation portfolio.  
This repository contains practical automation examples developed as part of my continuous growth in software testing and quality engineering.

The focus of these projects is to combine strong manual testing expertise with modern test automation approaches using Playwright, TypeScript, and Robot Framework.

---

# 📂 Repository Overview

## 1️⃣ TestWebsites

Automation of various dummy/demo websites to practice and demonstrate:

- End-to-End UI testing
- Form validation scenarios
- Negative test cases
- Regression flows
- Cross-browser execution

### Tools used:
- Playwright (TypeScript)
- Robot Framework
- Selenium
- Python (basic usage)

This project focuses on understanding test structure, reusable components, and maintainable automation patterns.
This was my first testing and my first map. The names are mostly just called 'test' since there are different testcases inside it.

## 2️⃣ TMAP Automation Project

Automation of selected flows on the TMAP.net website to align practical automation with structured test methodology principles.

### Focus areas:
- Functional UI validation
- Structured test scenarios
- Clear separation between test logic and test data
- Maintainable automation setup

### Tools used:
- Playwright (TypeScript)
- Robot Framework (Selenium)

This project reflects my TMAP-based testing mindset applied in automated form.

---

## 3️⃣ API Testing Project

API testing of a dummy/demo application using Playwright with TypeScript.

### Focus areas:
- API request validation
- Status code verification
- Response body assertions
- Data validation checks
- Basic negative API scenarios

### Tools used:
- Playwright (TypeScript)

This project demonstrates understanding of backend validation and API-level quality control in addition to UI testing.
